# Window Layouts

Snaps the front window to a half, a quarter, a third, the middle or the whole
screen, or sends it to the next display. Every layout is a command, so you can
type "left half" in the palette or give any layout a hotkey in Settings ›
Commands. Restore puts the window back where it was before its last snap.

- **Needs:** `.windows`: the host moves windows through Accessibility, so
  Stackbar asks for Accessibility access the first time. Stackbar 0.20.0 or
  later.
- **Surfaces:** panel (a button for every layout), settings.
- **Settings:** the gap left around snapped windows.
- **Commands:** Left Half, Right Half, Top Half, Bottom Half, the four
  quarters, First / Center / Last Third, First / Last Two Thirds, Maximize,
  Almost Maximize, Center, Next Display and Restore.
- **Not covered:** windows in full screen or on other Spaces. To remember a
  whole arrangement per monitor setup, use Workspaces.
