# Notes

A floating Markdown note pad on a hotkey, like Raycast Notes. Press ⌃⌥N, or
click the menu-bar icon, and a small window floats over whatever you are
doing with the note you were last in. Press it again to put it away.

- **Writing:** Markdown is styled as you type: headings, **bold**, *italic*,
  ~~strikethrough~~, `code`, quotes, links, lists and checklists. ⌘B, ⌘I,
  ⇧⌘X, ⌘E and ⌘K format the selection; Return continues a list and Tab
  indents it; ⌘Return or a click on the box ticks a task. The first line is
  the note's title.
- **Saving:** every word is saved as you type, even when you close the
  window mid-sentence. Notes stay on this Mac.
- **Finding:** the list button shows every note, pinned ones first, with
  checklist progress. "Search Notes" in the palette (alias `notes`) finds a
  note by any word in it. Back and Forward step through the notes you opened.
- **Getting notes out:** copy a note as Markdown, save it as a `.md` file, or
  ask Ask AI about it.
- **Deleting:** a deleted note waits in Recently Deleted for 30 days.
- **Needs:** 64 MB of storage. Stackbar 0.38.0 or later.
- **Surfaces:** menu bar (a click shows or hides the pad; right-click for the
  list), panel, window. The window floats until you unpin it with the pin in
  its title bar.
- **Commands:** Notes (show or hide the pad, ⌃⌥N), Create Note, Search Notes.
