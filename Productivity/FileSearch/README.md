# File Search

Files and folders by name in the command palette, from Spotlight's index.
Type three letters or more and the best matches show under Files in the
results, most recently used first, each with its Finder icon. Return opens
one; ⌘K shows it in Finder or copies its path. Search Files lists up to 20.
Apps, anything inside an app or bundle, hidden files and Library internals
are left out.

- **Needs:** finding files by name with Spotlight (names and paths in your
  home folder only, nothing is read from inside them), and opening what you
  pick. Stackbar 0.20.0 or later.
- **Surfaces:** panel (what you opened lately).
- **Commands:** Search Files, which also feeds the palette's results.
