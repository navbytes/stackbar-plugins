# Calculator

Sums and unit conversions answered right in the command palette. Type
`12*(3+4)`, `2^10`, `15% * 80`, `sqrt(2)`, `3h in min`, `72 f to c` or
`5 km in mi`, and the answer comes first in the results. Return copies it and
⌘Return pastes it. Plain numbers and words get no answer, so it never crowds a
normal search. The panel keeps your last ten answers.

- **Needs:** nothing. Stackbar 0.20.0 or later.
- **Surfaces:** panel.
- **Commands:** Calculate.
- **Units:** length, mass, time, data, volume and temperature. No currencies.
