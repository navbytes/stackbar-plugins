# Linear

Your Linear issues in the menu bar and the palette. The number is how many
assigned issues are in progress; the panel groups everything assigned to you
by state, ordered by priority.

- **Needs:** `api.linear.app` and the secret `LINEAR_API_KEY`, a personal API
  key from Linear (Settings > Security & access).
- **Surfaces:** menu bar, panel, settings.
- **On each issue:** Open, Copy Branch Name (Linear's own, so the branch links
  back to the issue), Copy Link, Copy ID.
- **Commands:** My Linear Issues, Search Linear Issues (by title), Create
  Linear Issue (team, title, description, priority, assign to me).
- **Settings:** what the menu-bar number counts, and the default team for new
  issues.
- **Agent tool:** `assigned` lists your open issues with their branch names.
